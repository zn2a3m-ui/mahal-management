# إدارتي المالية — نسخة الحسابات المستقلة

تطبيق أندرويد عربي يضم ثلاثة حسابات منفصلة تماماً:

1. **صندوق المحل:** رصيد افتتاحي، وارد ومصروفات، ديون العملاء وتحصيلاتها، وسجل الحركات.
2. **حساب الديون الشخصية:** ما لك وما عليك، الدفعات والزيادات والمتبقي لكل شخص، وصافي حساب مستقل.
3. **صندوق الجمعية:** رصيد افتتاحي، اشتراكات متوقعة ومبالغ محصّلة فعلياً، مشتريات، وسلف الأعضاء وتسديداتها.

لا تُرحّل أي حركة بين الحسابات الثلاثة تلقائياً. تسجيل دين زبون لا يخصم نقداً من صندوق المحل؛ الذي يضاف للصندوق هو المبلغ المحصّل فعلياً. رصيد الجمعية يعتمد التحصيلات المسجلة فعلياً، وليس الاشتراكات المتوقعة.

تبدأ النسخة دون أسماء أو مبالغ تجريبية. البيانات محفوظة محلياً على الهاتف مع نسخة احتياطية واسترجاع منفصل لكل حساب. تسجيل الدخول بحساب Google والمزامنة السحابية غير مفعّلين في هذه النسخة.
