# إدارتي المالية — نسخة الحسابات المستقلة

تطبيق أندرويد عربي يضم ثلاثة حسابات منفصلة تماماً:

1. **صندوق المحل:** رصيد افتتاحي، وارد ومصروفات، ديون العملاء وتحصيلاتها، وسجل الحركات.
2. **حساب الديون الشخصية:** ما لك وما عليك، الدفعات والزيادات والمتبقي لكل شخص، وصافي حساب مستقل.
3. **صندوق الجمعية:** رصيد افتتاحي، اشتراكات متوقعة ومبالغ محصّلة فعلياً، مشتريات، وسلف الأعضاء وتسديداتها.

لا تُرحّل أي حركة بين الحسابات الثلاثة تلقائياً. في صندوق المحل، تسجيل دين جديد على زبون يُخصم من الرصيد الحالي، وكل دفعة يسددها الزبون تُضاف إلى الصندوق. وتُعالج الديون القديمة المسجلة قبل هذا التعديل دون احتسابها مرتين. رصيد الجمعية يعتمد التحصيلات المسجلة فعلياً، وليس الاشتراكات المتوقعة.

تبدأ النسخة دون أسماء أو مبالغ تجريبية. البيانات محفوظة محلياً على الهاتف مع نسخة احتياطية واسترجاع منفصل لكل حساب. تسجيل الدخول بحساب Google والمزامنة السحابية غير مفعّلين في هذه النسخة.

## بناء APK
تُبنى نسخة Release موقّعة تلقائياً إذا كانت أسرار التوقيع الأربعة مضبوطة في GitHub Actions: ANDROID_KEYSTORE_BASE64 وANDROID_KEYSTORE_PASSWORD وANDROID_KEY_ALIAS وANDROID_KEY_PASSWORD. عند توفرها، نزّل Artifact باسم idarti-almalia-v2-release-apk. إذا لم تتوفر كلها، يُبنى Artifact تجريبي باسم idarti-almalia-v2-debug-apk. يرتفع رقم إصدار Android تلقائياً مع كل تشغيل.
